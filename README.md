- web application (Node.js UI)
- background operation (vercel cron to select employee of the day on 09:00)
- public API
  - /api/cats/GET
  - /api/cats/POST
  - /api/cats/{id}/GET
  - /api/cats/{id}/PUT
  - /api/cats/{id}/DELETE
- database for persistence (Neon PostgreSQL)
- file storage (vercel blob for cat photos)
- create/update validation
  - check if required fields are filled
  - check if email doesn't alrealy exist
  - check if date format is ok and if date is not in the future
  - check if photo is no more than 4 MB and JPEG, PNG or WebP file
- data input types
  - name/job title (string)
  - email (string)
  - salary (decimal)
  - birth date (date)
  - remote worker (boolean)
  - lives remaining (integer)
  - image type and size (file)
